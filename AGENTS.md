# go-surge

Unofficial Go client for the Surge SMS API, generated from Surge's public OpenAPI document. To use the client from an agent, read [.agents/skills/go-surge/SKILL.md](.agents/skills/go-surge/SKILL.md); this file is about changing the code.

## Architecture

One generated package, `surge`, at the module root, driven by `gen.go`:

`scripts/fetch-spec.sh` downloads the JSON document the Surge API serves at `https://api.surge.app/openapi.json` to `api/openapi.yaml`. `scripts/patch-spec.sh` writes `api/openapi.fixed.yaml`, downconverting nullable type lists, constants and schema examples to OpenAPI 3.0.3. oapi-codegen reads `config.yaml` and emits `client.gen.go`.

## Stack

- Go 1.26.10.
- oapi-codegen v2.8.0, pinned as a `tool` dependency in `go.mod`.
- Runtime: `github.com/oapi-codegen/runtime`.

## Layout

- `gen.go`, `config.yaml`, `client.gen.go`: the package.
- `client_test.go`, `example_test.go`: tests, including the README example.
- `scripts/`: spec download, downconversion, lint and security scans.
- `api/`: downloaded original and patched specs, gitignored.
- `vendor/`: dependency sources, regenerated by `make dep` and intended for version control.

## Dev workflow

Everything runs in the `Dockerfile.dev` image. You need Docker and Make.

```bash
make dep       # go mod tidy + go mod vendor
make generate  # download the spec and regenerate
make lint      # shellcheck, shfmt, go fix, golangci-lint
make test      # go test -race
make sec       # gitleaks, govulncheck, semgrep
```

## Project-specific landmines

- The downloaded `api/openapi.yaml` is JSON. The patch uses jq, not a YAML parser.
- OpenAPI 3.1.1 nullable type lists, `const` and schema examples arrays need downconversion. Never hand-edit generated output.
- `skip-prune` retains all schemas, including webhook payload models. There is no webhook server or signature verifier.
- All unformatted number fields map to `float64`.
- Authentication is `Authorization: Bearer <token>` at `https://api.surge.app`. Account IDs are separate path parameters.
- `MessageParams` has conversation and direct recipient union branches. Sending is asynchronous; creation does not prove delivery.
- HTTP failures return parsed response fields and status codes. Go errors cover transport and decoding failures.
- Pagination is manual, using `After` and `Pagination.NextCursor`.
- `make generate` always downloads the current spec. Review the generated diff.
- `.github/workflows/regen.yml` regenerates daily and releases passing changes. Fixes may not touch its `fix_protected_paths`: workflows, Makefile, AGENTS.md, rules, scanners, lint and download scripts or their configs. Such failures need a manual fix.
- `make sec` skips history scanning only when no Git metadata exists. It always scans the directory.
- Gitleaks allows only the spec's exact sample JWT in `client.gen.go`. Do not broaden this exception.
